# 🚀 Quick Publish Checklist

## Before First Publish

- [ ] Update `package.json` with your name/email in `author` field
- [ ] Update `package.json` with repository URL (if you have one)
- [ ] Login to npm: `npm login`
- [ ] Check package name availability (it should be unique)
- [ ] Run `npm run build` to verify build works
- [ ] Test the built package locally if possible

## Every Publish

- [ ] Make your code changes
- [ ] Test with example app: `npm run example`
- [ ] Update README.md if needed
- [ ] Run `npm run build`
- [ ] Bump version: `npm version patch|minor|major`
- [ ] Run `npm pack --dry-run` to verify what will be published
- [ ] Publish: `npm publish`

## Quick Commands

```bash
# Build
npm run build

# Check what will be published
npm pack --dry-run

# Publish patch (1.0.0 -> 1.0.1)
npm run publish:patch

# Publish minor (1.0.0 -> 1.1.0)  
npm run publish:minor

# Publish major (1.0.0 -> 2.0.0)
npm run publish:major
```

## ✅ Remember

- **You CAN update anytime** - just bump the version!
- **Version must increase** - can't republish same version
- **Test before publishing** - always run build first
- **Git tags are auto-created** - `npm version` creates tags
